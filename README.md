# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student marks and attendance using **Pandas and NumPy**. It calculates total marks, averages, grades, pass/fail results, and identifies top-performing students.

## Objectives
- Analyze student academic performance.
- Calculate total marks and average marks.
- Assign grades based on average marks.
- Determine pass/fail results.
- Perform subject-wise performance analysis.
- Identify the top-performing students.

## Technologies Used
- Python
- NumPy
- Pandas
- Google Colab

## Dataset Description
The project uses a CSV dataset containing 20 student records.

**Columns:** Student ID, Name, Department, Maths, Python, AI, Attendance.

## Features
1. Loads student data from a CSV file.
2. Calculates total and average marks.
3. Assigns grades automatically.
4. Determines pass/fail status.
5. Calculates class and subject-wise averages.
6. Displays the best-performing subject.
7. Identifies the top 3 students.
8. Generates a complete student performance report.
9. Includes project testing using assertions.

## Grading Criteria
| Average Marks | Grade |
|---|---|
| 90 and above | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| Below 60 | F |

**Pass/Fail Rule:** A student passes if they score at least 40 marks in every subject.

## Project Files
- `Student_Performance_Analytics.ipynb` — Python code and analysis

## How to Run
1. Open Google Colab.
2. Upload `Student_Performance_Analytics.ipynb`.
3. Upload `students.csv` to the Colab session.
4. Run the notebook cells in order.
5. View the student performance analysis and final report.
